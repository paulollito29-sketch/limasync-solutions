# LIMASYNC SOLUTIONS — Architecture Guidelines

This project is built purely with **Astro 5**, React 19 islands, Framer Motion, and CSS custom properties.

- Framework: **Astro 5** (`static` output mode)
- Styling: `src/styles/global.css`
- Components & Islands: `src/components/`
- Pages & Routes: `src/pages/`
- Production Host: Vercel (`framework: "astro"`)
