# LIMASYNC SOLUTIONS — Sitios Web y Automatización en Lima

Sitio web corporativo y plataforma de captación de clientes desarrollado con **Astro 5**, React 19, Framer Motion y Tailwind/CSS moderno.

## 🚀 Tecnologías

- **Astro 5** (Static Site Generation con soporte i18n y sitemap automático)
- **React 19** (Islas interactivas con `client:load` y `client:visible`)
- **Framer Motion** (Animaciones fluidas y botón flotante de WhatsApp)
- **Vercel** (Despliegue estático de alto rendimiento con CDN global)

## 🛠️ Comandos de Desarrollo

```bash
# Iniciar servidor de desarrollo en http://localhost:3000
npm run dev

# Compilar proyecto para producción
npm run build

# Previsualizar el build de producción
npm run preview
```
